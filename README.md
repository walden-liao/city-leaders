# 中国地级市领导分工查询表

搜城市名，看这个市的市长、副市长分别是谁，分工原文写了什么，财政归谁管。293 个地级市，数据来自各市政府官网公开的分工通知与领导之窗页面，2026 年 10 月快照。

公开试用版，纯静态网页，无后端、无框架。网页运行只需 index.html 和 data.json。项目起源于七篇知乎研究文章的数据沉淀，当前先开放城市分工查询模块；其他主题尚未进入工具。

试用版尚未完成全量现行核验。收录完整度不代表准确率，旧版人员和自动解析错误仍可能存在；请通过官网原文确认。修订过的记录显示复核时间、范围和来源，CSV 同步包含这些信息。

## 数据现状

本表统计的是公开文本，不是实际分工。每个市在页面上标有收录状态和文本年份：

| 收录状态 | 含义 | 市数 |
|---|---|---|
| 人员较全 | 收录人数不少于班子人数减一 | 39 |
| 部分收录 | 有人员明细，但不全，或班子人数未知 | 150 |
| 仅财政归属 | 已从原文判定财政归属，未收录人员明细 | 77 |
| 未收录 | 两者都没有，不代表该市没有公开分工 | 27 |

另有 21 个市的分工文本早于 2024 年，页面用橙色年份提示班子可能已调整。

财政归属口径：A 市长兼管或负责财政、常务协助分管；B 常务直接分管财政局；C 双方均未提及；D 财政落在非常务副市长名下；E 其他变体；不明确指分工页不全。

## 文件结构

```
index.html            页面、样式、脚本
data.json             清理后的数据，页面直接读取
tools/data_raw.json   原始抓取结果，不手改
tools/clean_data.py   清理脚本，从 data_raw.json 生成 data.json
```

清理脚本做的事：删除抓取时被误识别为人员的正文碎片和备注，按下一个人名切开串段的分工文本，标记被截断的分工，补正只记了市长一人的班子人数。修改清理规则后运行 `python3 tools/clean_data.py` 重新生成即可。

## 部署到 GitHub Pages

1. 新建仓库，上传 index.html、data.json、tools/ 和 .github/，以及本 README 和 .gitignore。docs/ 当前含个人电脑绝对路径及内部工作记录，公开仓库前应单独整理，不要直接整目录上传。
2. 仓库 Settings → Pages，Source 选 GitHub Actions。默认分支使用 main，推送后工作流只将 index.html、data.json 和 .nojekyll 部署到 Pages，不会把研究底表和内部文档部署到站点。
3. 一两分钟后访问 `https://你的用户名.github.io/仓库名/`。

可在本地运行 `python3 tools/build_trial.py` 生成 dist/ 发布目录。每次修改原始数据或清理规则后，先运行 `python3 tools/clean_data.py`，检查生成的 data.json，再提交。复核记录保存在 tools/fiscal_reviews.json 中，生成时会校验对应分类。仓库 Issues 需开启，城市卡片会预填反馈信息。

CSV 一行对应一条人员记录；未收录人员的城市保留一行，因此 CSV 行数通常大于城市数。搜索与筛选会保存在网址参数中，刷新后恢复；“重置”清空全部条件。访问统计默认关闭。

部署在 github.io 上时，每张卡片底部的报错或补充链接会自动指向本仓库的 Issues，并预填城市信息。部署在其他域名时，在 `index.html` 顶部的 `CONFIG.repo` 填上仓库地址。

本地预览不能直接双击打开（浏览器会拦截 `fetch`），在文件夹里运行 `python3 -m http.server` 后访问 `http://localhost:8000`。

## 访问统计（可选）

想知道有没有人用、搜了什么，可以接入免费的 [GoatCounter](https://www.goatcounter.com/)：注册后把 `https://你的代码.goatcounter.com/count` 填进 `index.html` 顶部的 `CONFIG.goatcounter`。会记录页面访问、搜索词、展开了哪个市、点击原文、导出 CSV 和报错链接。留空则不加载任何统计脚本。

## 搜索规则

支持中文、全拼、首字母、省份。按匹配程度排序：城市名完全相同，城市名开头，城市全拼开头，城市首字母，省份。同一档里省会和计划单列市优先，其次是一份手工维护的经济大市名单（`TIER2`），再按省份排。

## 反馈

数据有错或想补充某个市，欢迎提 Issue，最好附官网链接。
